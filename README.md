# سیستەمی پشکنین و تۆمارکردنی ئوتومبێل – بەڕێوەبەرایەتی هاتووچۆی پارێزگای سلێمانی
## Car Registration & Inspection Management System

سیستەمێکی تەواو بۆ بەڕێوەبردنی هۆبەی پشکنین و تۆمارکردنی ئوتومبێل بە فۆنتی سپێدە (Speda) و پشتگیری کیبۆردی C4Kurd، پەیوەستکراو بە بنکەی داتای SQL Server.

### تایبەتمەندییەکان:
- **تۆمارکردنی ئوتومبێلی نوێ (پشکنین):** ڕێکخستنی هاوشێوەی فۆرمی C# بە تەواوی خانەکان و ڕەنگەکان و بارکۆد.
- **تۆماری گومرگ (Customs):** تۆمارکردن و گەڕان لە ئوتومبێلە گومرگییەکان.
- **دانانی نیشانەی حیجز و لابردنی:** بەڕێوەبردنی ئوتومبێلە حیجزکراوەکان بە پەڕەی چاپکردن.
- **تۆماری لێدراوی (RAP) و گومانلێکراو:** پشکنینی ڕاستەوخۆی ژمارەی شاسی و تابلۆ بۆ دۆزینەوەی ئوتومبێلی کێشەدار.
- **گەڕانی وورد (Advanced Search):** گەڕان بەپێی ٩ فلتەری جیاواز.
- **ڕاپۆرت و ئامارەکان:** گراف و خشتەی ئاماری ڕۆژانە و گشتی بەشەکان.
- **تۆماری کەسی و کارمەندان:** بەڕێوەبردنی دەسەڵاتەکان و یوزەرەکانی هۆبەی پشکنین.

### کارپێکردن:
```bash
npm install
node server.js
```
پاشان سەردانی ناونیشانی خوارەوە بکە:
`http://localhost:3000`
